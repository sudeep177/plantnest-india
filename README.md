# PlantNest India — web app starter

Mobile-first gardening web app starter for Indian home gardeners.

## Features
- Add plants by name and optional photo
- Local plant collection saved in this browser
- Starter care guides for Tulsi, money plant, snake plant, aloe/succulents, hibiscus, jasmine, marigold, bougainvillea, rose and curry leaf
- Symptom-based troubleshooting
- Web-app manifest and basic offline cache

## Limitations
This prototype has no account, cloud sync, live AI, or true photo diagnosis. Images and plant data are stored on this device/browser. Notification permission can be requested, but reliable scheduled reminders need a hosted HTTPS app and a notification service. Do not place private API keys in browser code.

## Install on iPhone
1. Upload the folder to an HTTPS static host.
2. Open the hosted URL in Safari on iPhone.
3. Tap Share → Add to Home Screen → Add.
4. The icon opens the app-like experience.
